# Исходные задания RuReviews / WB

150 отдельных файлов `wb_<source_review_id>.json` без ответов и звёзд.
Все задания включены в общий файл
`../annotations/partner_reviews/review_tasks_partner.json`.
Импортируйте либо общий файл, либо отдельные файлы, чтобы не создать повторы.
Каждый объект содержит постоянный sample_id RV0001–RV0150 и сведения об источнике.
Не переименовывайте sample_id после передачи партии второму участнику.

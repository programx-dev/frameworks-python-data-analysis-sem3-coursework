# Источники фотографий дронов

Найди фотографию по имени файла через Ctrl+F. Скопируй содержимое каждого блока в соответствующее поле Label Studio.

Авторы приведены полностью по сохранённому полю Artist страниц Wikimedia Commons, включая организацию, звание и другие указанные сведения. Лицензии приведены по полю LicenseShortName.

Номер в имени файла не является ID задачи Label Studio.

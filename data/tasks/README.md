# Задания Label Studio

JSON задач содержит только `data` из независимого экспорта, без аннотаций,
предсказаний и черновиков. Задачи имеют постоянные sample_id.

## Изображения

1. Запустите Label Studio скриптом из `scripts`, чтобы корнем локальных файлов был `data`.
2. Создайте новый проект. В Settings → Labeling Interface → Code вставьте
   содержимое `images/labeling_interface.xml`.
3. Один раз импортируйте `images/image_tasks.json`: 103 задачи без рамок.
4. Источник, автор и лицензия отображаются из `data`; вручную заполнять их не нужно.

Фотографии лежат в `data/images/birds` и `data/images/drones`.
Не загружайте их повторно через Upload или Sync: ссылки уже содержатся в JSON.
Для восстановления полной старой разметки Никиты с редактируемыми текстовыми
ответами предусмотрен `images/labeling_interface_nikita.xml`.

## Отзывы

Создайте отдельный проект, вставьте `reviews/labeling_interface.xml` и импортируйте
`reviews/review_tasks.json`: 150 задач без ответов. Тексты внутри JSON;
локальное хранилище не требуется. Файлы из `data/reviews` — те же отзывы,
не импортируйте их дополнительно в этот проект.

## Экспорт

Export → JSON, полный формат. Сохраняйте свой экспорт в `data/annotations/nikita`
или `data/annotations/egor` с соответствующим именем файла. Не меняйте sample_id.
До завершения независимого этапа не просматривайте ответы второго участника.
Генерация и проверка задач описаны в `scripts/README.md`.
